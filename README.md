# DAWショートカット辞典

Logic Pro のショートカット（キーコマンド）を、スマホで探して「どう押すか」を確かめるWebアプリ。

- モックアップ: https://claude.ai/artifact/MnwuGiqbNtRfeRzSiEnPNL （`keykoma.html` を公開したもの）
- 本体: `keykoma.html`（画面と仕組み。外部サービスに依存しない）
- データ: `data/scenes.js`（どのDAWでも共通の場面一覧）、`data/logic-pro.js`（Logic Pro のショートカット）。DAWを足すときは `data/` にファイルを1つ追加する
- `data/logic-pro.js` は `python3 tools/build_logic.py` で Apple 公式ガイドから作る（手で直さない）。言いかえ語・覚え方・「基本」に入れるものは `tools/logic_extra.py` に書く
- Webアプリ版：`python3 tools/build_web.py` で `docs/` に組み立てる（keykoma.html を普通の Web ページに包み、ホーム画面用の manifest、電波なしで動かす sw.js、アイコンを添える）。keykoma.html やデータを直したら、組み立て直してから保存する
  - 公開中の住所：https://daw.shortcut-jiten.workers.dev （Cloudflare のアカウント名 shortcut-jiten ＋ Worker 名 daw。Worker 名は wrangler.jsonc の name と Cloudflare 側でそろえる）
  - 公開先は Cloudflare Workers。設定は wrangler.jsonc（docs/ をそのまま配るだけ）。Cloudflare とこのリポジトリをつなぎ、main ブランチに入ったものが公開される。作業は作業用ブランチで行い、公開したい段階で main に取り込む
  - このリポジトリは公開（public）リポジトリ
  - アイコンの元は tools/icon.html。`node tools/make_icons.js docs/icons` で PNG にする
- 公式ガイド（support.apple.com）を読むには、クラウド環境のネットワーク設定で `support.apple.com` を許可する必要がある

## 決まっている方針

- 対象は Logic Pro（最新版）から。データと画面を分け、あとで Final Cut Pro などに広げられるようにする
- スマホ中心。検索とキーボード図を1画面にまとめ、横向きではキーボードを大きく表示する
- 主役は「検索したショートカットをどう押すか」。キーをタップして機能を調べる使い方はおまけ
- 修飾キー（⌘⌥⇧⌃）は普段は目立たせず、使うときだけそれぞれの色で光らせる（⌘青・⌥緑・⇧オレンジ・⌃ピンク）
- 検索は課金なし。各ショートカットに言いかえ語を大量に登録し、あいまいな言葉でも上位3つの候補を出す
- 「やりたいこと」からの枝分かれ（例：録音する → 始める・止める → ショートカット）でも探せる
- 収録は初期設定で割り当てのあるショートカットすべて。Apple 公式の日本語ユーザガイドをもとに作る
- キーボードは設定で4種類から選べる（Apple US／Apple JIS／Windows用 US／Windows用 JIS）。「control と caps lock を入れ替える」スイッチもある
  - Windows用は Mac につなぐと Windows キーが ⌘、Alt キーが ⌥ になるので、図の ⌘ に「win」、⌥ に「alt」と刻印名を出す
  - 自由にキーを動かせる機能は作らない（大がかりになるため）
- アプリ名の見た目は「機材の刻印風」：細めの文字で字間を広く（DAW ショートカット辞典）。どのカラーでも同じ
- 設定は右上のボタン（フェーダーの形のアイコン）から開く。キーボード・カラー・データの引っ越しをまとめる
- ★マイリスト・覚えた・自分のメモ・最近見た は端末のブラウザに保存。書き出し／読み込みで引っ越せるようにする
- デザインは音楽的であることが前提。カラーは v2 で12種類を見比べ、v3 で6種類＋自動に絞った
  - 自動／アルミ（ハイコントラストと統合して文字をくっきり）／ミキサー／アンプ／GB（グレーの本体に黄緑の液晶）／シンセ（白とグレーに黄色をひとつ。旧「白い家電」）／ピアノ（細身の上品なゴシック体）。名前は短い一語にしている
- 詳細画面は置かない。覚え方は液晶に直接出し、自分のメモは「✎ メモ」ボタンから書く
- 「やりたいことから探す」は畳める（最初は畳んだ状態）
- まずアーティファクトで作り、のちに独立したWebアプリ（GitHub Pages など、ホーム画面に追加・オフライン対応）にする

## リリースと今後の広げ方

- 最終的には、Logic Pro 以外のDAW（音楽制作ソフト）にも対応するアプリとして仕上げる
- リリースはまず Logic Pro 版を出し、ほかのDAWは順に追加していく
- 追加候補: Ableton Live、Cubase、Studio One、FL Studio、Pro Tools など。DAWのあとは動画編集（Final Cut Pro が最初の候補）や Excel にも広げられる

### 今のうちに整えておくこと（Logic Pro 版を作る段階で対応する）

- **アプリ名**: 「DAWショートカット辞典」に決定（旧名：キーコマ帳）。全DAW共通の名前とし、最初のリリースは「DAWショートカット辞典 ― Logic Pro 版」のように対応ソフトを添える
  - ホーム画面に追加したときの短い表示名は「DAW辞典」などにする（Webアプリ化のときに設定）
  - 2026年10月時点のネット検索では、同じ名前のアプリや本は見つからなかった。リリース前に商標も含めて改めて確認する
- **DAWを選ぶ場所**: 左上の「Logic Pro 12」の表示を、あとでDAWの切りかえボタンにできる位置・作りにしておく
- **データの形**: 1件ごとに「どのソフトのショートカットか」を持たせ、ソフトごとに別のファイルにする。追加はデータを1つ足すだけで済むようにする
- **共通の「やりたいこと」**: 場面（録音する・編集する など）と言いかえ語は、どのDAWでも同じ言葉で探せるように共通の一覧として作る。DAWを乗りかえる人にも役立つ

### お金の取り方（方針）

- **基本機能はすべて無料**で公開し、「コンビニのコーヒー1杯分（300円）」の**応援（寄付）**を受け取る
  - 受け取り先の候補：OFUSE（日本のサービス）または Ko-fi（コーヒーがテーマ、受け取り手数料なし）。支払いは相手のサービスの画面で行うので、Cloudflare 無料プランの「カード情報を扱わない」決まりにも当たらない
  - ボタンは「マイ」画面と設定画面のいちばん下に「☕ コーヒーを1杯おごる（300円）」として置く（検索・一覧には出さない）
  - 応援の受け取り額によっては確定申告が必要になる
- 有料（または応援してくれた人へのお礼）の機能は、反応を見てから足す
  - ◎ 候補：おすすめのカスタムキー（初期設定にない便利な割り当ての提案。一番の目玉。割り当てのない機能の一覧を Logic Pro から集める必要あり）、早見表（PDF・壁紙）、自分の割り当ての登録、追加のカラー
  - ○ 無料にするもの：検索（全件）、一覧・キーボード図で調べる機能、ほかの DAW の対応、テンキーの表示、マイリスト・メモ・書き出し／読み込み
  - △ 保留・見送り：練習モード（作るなら無料のおまけ）、乗りかえ早見、端末どうしの同期、一覧の制限（無料は初級だけ）、1日に調べられる件数の制限（20件）、広告
- 公開先は Cloudflare Workers（無料プラン）。有料の機能を売る段階では有料プラン（月5ドル程度）と外部の決済サービスを検討し、その時点の規約を確認する

### ほかのDAWを足すときの課題

- **Windows 対応**: Windows 用のキーボード図と、Ctrl・Alt など Windows のキー表示が必要
- **自分で割り当てを変えている人が多い**: 予定している「自分の割り当て」機能が大事になる
- **公開時の注意**: ソフト名を「対応ソフト」として書くのは問題ないが、各社のロゴは使わない。公式ガイドの文章はそのまま写さず、説明文は自分たちで書き起こす

## 現在の状態（試作版 v4）

- タブは「さがす・練習・マイ」
- 収録は Apple 公式ユーザガイド「キーコマンドの表」（26ページ・837行）から、初期設定でキーのある812件
  - 機能名とJIS配列のキーは日本語版、US配列のキーとテンキーの印は英語版から取り、行ごとに突き合わせている
  - 日本語版と英語版で食い違う2件は英語版を採用し、`chk` の印を付けた（要確認）
- 探し方は「一覧から探す」の1つの欄にまとめ、［やりたいこと（場面15個＋基本）｜使う画面（14個）］を切りかえる。項目は名前と件数だけの小さな札。いつも表示（畳まない）。その下に「直前の検索」（最後に選んだショートカット）を出す。「よく使うもの」はやめ、「基本」にした
- 場面の振り分けは機能名の言葉から自動（言いかえ語を付けたものは手で見直し済み）
- 言いかえ語：812件すべてに付けた。覚え方：475件（頭文字や記号の形で本当に覚えられるものだけ）。ツールメニューの24件には「T でツールメニューを開いてから押す」と注意書き
- 検索の順位：言いかえ語が同じくらい当てはまるときは、機能名にその言葉が入っているもの、「基本」に入っているものを上にする
- 書き出し／読み込み：設定画面から。ファイル（.json）か文字のコピーで移せる。読み込みは足し合わせ（消さない）。番号に加えて名前と画面も書き出し、データを作り直して番号がずれても照合できる。Claude 内では downloads の仕組みで保存
- 練習モード、自分の割り当ては未実装
